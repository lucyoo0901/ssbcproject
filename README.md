# 2026 성도교제밤 촬영일자

GitHub Pages로 배포하는 촬영 일정 페이지입니다.

- **누구나**: 캘린더(2026년 11~12월), 날짜별 씬 스케줄, 씬별 콘티 이미지, 촬영 인원을 볼 수 있습니다.
- **관리자**: 오른쪽 위 **✎ 수정** 버튼을 눌러 GitHub 토큰으로 로그인한 뒤 일정을 고칠 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 뼈대 (첫 화면) |
| `style.css` | 디자인 |
| `app.js` | 동작 (캘린더, 수정, 저장) |
| `data.json` | **모든 일정·인원 데이터** (관리자가 저장하면 이 파일이 바뀝니다) |
| `images/scenes/` | 관리자 화면에서 올린 콘티 이미지가 저장되는 곳 |
| `images/locations/` | 관리자 화면에서 올린 장소 사진이 저장되는 곳 (첫 업로드 때 자동 생성) |
| `images/sample/` | 예시 이미지 (실제 데이터를 넣은 뒤 지워도 됩니다) |
| `.nojekyll` | GitHub Pages가 파일을 가공하지 않고 그대로 올리도록 하는 빈 파일 |

## 1. 배포하기 (처음 한 번)

1. GitHub에서 **New repository**로 새 저장소를 만듭니다. 이름은 영어로 정합니다(예: `sungdo-night-2026`). 무료 계정이면 **Public**이어야 합니다.
2. 저장소 첫 화면의 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
3. 이 폴더 **안의 내용 전체**(파일과 `images` 폴더)를 끌어다 놓고 **Commit changes**를 누릅니다.
   - 폴더 자체가 아니라 **안의 내용**을 올려야 `index.html`이 저장소 맨 위에 놓입니다.
   - `.nojekyll`처럼 점(.)으로 시작하는 파일은 탐색기에서 안 보일 수 있습니다. 빠졌다면 **Add file → Create new file**에서 이름을 `.nojekyll`로, 내용은 비워 둔 채 만들면 됩니다.
4. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/ (root)** 로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나타납니다: `https://아이디.github.io/저장소이름/`

### 코드를 고쳐서 다시 올릴 때

`app.js`나 `style.css`를 바꿔 올렸다면 `index.html` 안의 `?v=1`을 `?v=2`처럼 올려 주세요. 방문자 브라우저가 옛 파일을 계속 쓰는 일을 막아 줍니다. 일정 데이터(`data.json`)는 신경 쓰지 않아도 됩니다.

## 2. 관리자 토큰 만들기 (관리자만)

1. GitHub 오른쪽 위 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. **Repository access**: *Only select repositories*를 고르고 이 저장소만 선택합니다.
3. **Permissions → Repository permissions → Contents**: **Read and write**로 설정합니다.
4. 만료일을 행사 이후(예: 2027년 1월)로 정하고 생성합니다. 토큰은 한 번만 보이니 안전한 곳에 보관하세요.
5. 사이트에서 **✎ 수정** → 저장소(`아이디/저장소이름`)와 토큰을 입력하면 관리자 모드가 됩니다.

> 토큰은 비밀번호와 같습니다. 다른 사람과 공유하거나 채팅·문서에 붙여 넣지 마세요. 로그인 정보는 브라우저 탭을 닫으면 지워집니다.

## 3. 사용 방법 (관리자)

- **일정 추가**: 캘린더 날짜 칸의 **+** 버튼이나, 날짜를 눌러 열린 패널의 **+ 일정 추가**를 누릅니다. 종류(촬영/편집/회의/기타), 시간, 장소, 참여 인원을 넣습니다.
- **씬 추가**: 일정 카드의 **+ 씬 추가**에서 촬영 시간, 씬 번호, 제목, 설명, 등장 배역, 콘티 이미지를 넣습니다. 이미지는 여러 장을 한 번에 고를 수 있고, ↑↓로 순서를 바꿉니다. 큰 사진은 자동으로 줄여서(최대 1600px) 올립니다.
- **촬영 스케줄**: 촬영일만 모아 나란히 보여 줍니다. 장소별로 씬이 묶이고, 장소가 바뀌는 곳에 🚚, 이미 갔던 장소로 돌아가면 ↩ 재방문 경고가 붙습니다. 씬에 마우스를 올리면 등장 배역과 준비물이 뜨고(휴대폰은 눌러서 펼치기), 아래 ‘배역 등장 순서’ 표에서 배역별 출연 씬과 대기 씬을 볼 수 있습니다.
- **촬영 장소**: 왼쪽 **촬영 장소** 메뉴에서 장소 이름, 주소, 좌표(현장에서 ‘지금 내 위치 넣기’), 메모, 사진을 등록합니다. 장소를 누르면 지도, 카카오맵·네이버 지도 바로가기, 사진 갤러리, 그 장소에서 찍는 씬 목록이 나옵니다.
- **씬별 장소**: 일정과 씬에서 등록된 장소를 골라 씁니다(목록에 없으면 그 자리에서 새 이름으로 추가). 씬 장소를 비워 두면 일정 장소를 그대로 쓰고, 다르면 일정 패널에 빨간 📍 표시가 붙습니다.
- **준비물**: **준비물 → 준비물 목록**에 품목과 담당을 등록하고, 일정(공통)과 씬에서 골라 씁니다. 같은 품목은 일정 준비물에서 하나로 합쳐지고, 옆에 ‘공통 · S#1 · S#2…’처럼 쓰이는 씬이 함께 표시됩니다. **일정별** 탭에서 날짜별 전체 목록과 준비 현황을 보고, 관리자는 체크 박스로 ‘준비 완료’를 표시합니다(저장해야 반영).
- **대본 / 스토리보드**: 해당 메뉴에서 오른쪽 위 **링크 설정**을 눌러 구글 문서 주소를 넣습니다.
  - 구글 문서의 **공유 → 일반 액세스: 링크가 있는 모든 사용자(뷰어)** 로 바꿔야 다른 사람도 보입니다.
  - 원본 문서를 고치면 페이지에도 자동으로 반영됩니다(새로고침하면 최신 내용). 구글 프레젠테이션, 드라이브의 PDF 주소도 넣을 수 있습니다.
  - 휴대폰에서는 문서가 작게 보일 수 있으니 **새 창에서 열기**를 쓰면 편합니다.
- **촬영 인원**: 왼쪽 메뉴에서 배역 ↔ 배우, 역할 ↔ 스태프 이름을 짝지어 등록합니다.
- **저장**: 다 고친 뒤 오른쪽 위 **저장**을 눌러야 모두에게 반영됩니다. 사이트 반영까지 1~2분 걸립니다.

### 토큰 없이 미리 편집

로그인 창의 **토큰 없이 미리 편집**을 누르면 이 브라우저에서만 수정해 볼 수 있습니다. **data.json 받기**로 파일을 내려받아 저장소의 `data.json`을 바꿔 올리면 반영됩니다. 이 방식에서는 이미지가 data.json 안에 함께 들어가므로 이미지가 많으면 토큰 로그인 방식을 쓰세요.

## 알아 두실 점

- 공개 저장소이므로 data.json과 이미지는 누구나 볼 수 있습니다. 연락처 같은 개인정보는 넣지 마세요.
- 씬에서 지운 이미지 파일은 저장소에 남아 있습니다. 필요하면 `images/scenes/`에서 직접 지우세요.
- 두 사람이 동시에 수정하면 나중에 저장한 사람에게 "다른 곳에서 먼저 수정되었습니다" 안내가 나옵니다. 나가기 후 다시 로그인해서 고쳐 주세요.
